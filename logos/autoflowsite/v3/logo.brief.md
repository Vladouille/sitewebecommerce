# AutoflowSite — v3, logos carrés (provenance)

Demande : retirer le triangle et les formes abstraites, mettre un objet concret, changer couleurs et police, retirer le slogan, format carré utilisable partout.

- Format : carré 512×512, contenu gardé dans le cercle inscrit (recadrage rond d'Instagram, Google, WhatsApp).
- 1. Écran + mini-site : #14213D / #FFFFFF / #FCA311, Plus Jakarta Sans 800.
- 2. Écran + mobile : #0D4D40 / #FFFFFF / #6EE7B7, Manrope 800.
- 3. Portable + clic : #FFFFFF / #1E1B4B / #FF5A4E, Sora 700.
- Lettrage converti en tracés. Polices Google Fonts sous licence OFL, téléchargées depuis github.com/google/fonts (ofl/<nom>/<Nom>[wght].ttf), instance statique au poids indiqué.
- `-favicon.svg` : mini-site simplifié, sans le nom (illisible sous 48 px).
- Générateurs : `build_logos_v3.py` (FONTDIR = dossier des .ttf), `montage_v3.js` → `planche-v3.png`.
